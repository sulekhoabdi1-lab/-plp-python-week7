# Week 7 Assignment: My Notes & The Report Builder

## Files

- my_notes.py - Writes, appends, reads and counts notes.
- my_notes.txt - Stores the four notes.
- report_builder.py - Reads CSV data and creates a learner report.
- hubs.csv - Contains learner names, hubs and scores.
- report.txt - Contains the learner report and average score.

## What happens if we change "a" to "w"?

If we change "a" to "w", the file will be overwritten instead of adding a new note. The first three notes will be erased, and only the fourth note will remain.
